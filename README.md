# House Prices: прогноз стоимости жилья

Проект на датасете Kaggle House Prices (Ames Housing) — регрессионная задача, где по набору характеристик дома (площадь, качество отделки, год постройки, наличие гаража, подвала и так далее) нужно предсказать его цену продажи, SalePrice. Используется вариант соревнования для Kaggle Learn, где метрикой качества выступает MAE в долларах.

Перед моделированием проведена содержательная предобработка: пропуски в структурных признаках (наличие бассейна, гаража, подвала, ограды и т.п.) заполняются как отсутствие соответствующего объекта, а не медианой, поскольку NaN в этих колонках означает "такого элемента у дома нет". Обнаружены и удалены явные выбросы — несколько домов с очень большой жилой площадью, но при этом низкой ценой, которые искажали бы регрессию. Целевая переменная логарифмируется (log1p), чтобы сгладить её скошенное распределение и сделать метрику более устойчивой к домам с высокой ценой. Дополнительно проведён корреляционный анализ, чтобы понять, какие признаки сильнее всего связаны с ценой.

Для самого моделирования числовые и категориальные признаки обрабатываются раздельно внутри одного sklearn Pipeline: числовые — импутация медианой и стандартизация, категориальные — импутация модой и one-hot encoding. В качестве baseline взята Ridge-регрессия, после чего через кросс-валидацию сравнивается сразу несколько моделей — линейная регрессия, Ridge, Lasso, ElasticNet, KNN, XGBoost и LightGBM. Для каждой из них отдельно подбираются гиперпараметры: линейные модели и KNN — через GridSearchCV, градиентный бустинг — через RandomizedSearchCV, так как пространство параметров там заметно больше. По итогам сравнения лучшей оказалась настроенная Lasso-регрессия, на которой и обучается финальная модель для генерации предсказаний.

Проект состоит из одного notebook и папки data с исходными файлами соревнования; результатом работы служит submission.csv с предсказанными ценами для тестовой выборки.

Итоговая модель — тюненая Lasso — показала на публичном лидерборде Kaggle результат 13351.17915 по метрике MAE (в долларах), что говорит о достаточно точных предсказаниях с учётом масштаба цен на жильё в датасете.
